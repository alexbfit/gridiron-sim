# SaberSim archive + backtests, 2024–2026 (2026-09-25)

## Data (Alex's SaberSim account → `DFS DATA/_sabersim_archive/`, README inside)
- SaberSim keeps DK slates back to the **2024 season** only (2023 dates: "No NFL slates").
- Per Sunday main slate: every player's salary, SS projection, p25–p99, stat-line projections, SaberSim "actual", and the **full Contest Flashback leaderboards** — every entry's lineup, points, rank, real payout, stack type, lineup ownership, hashed user — for the $20 Millionaire, $3 Play-Action (20-max) and $0.50 mini-MAX. 2024 wk 1–18, 2025 wk 1–18, 2026 wk 1–2. ~10M entries.
- Leaderboard files are `https://firebasestorage.googleapis.com/v0/b/sabersimui-contests/o/dk%2Ffinal%2Fcontest_<DK id>.json?alt=media` (no login needed; the DK id is on each contest card). Player ids are SaberSim UUIDs, stable across seasons; names/salaries come from scraping the projections grid.
- SaberSim's "Actual" is sometimes off by 1–7 pts; player points were re-fit so every leaderboard total matches exactly (0 mismatches all weeks).
- **SaberSim's ownership on past slates is post-contest ownership** (r = .99 with the real field), not the pre-lock projection — it cannot be backtested. Live, before lock, it is their projection.
- No Flashback for the $5 week-1 Millionaires; week 1 uses the Play-Action. Some Play-Action / mini-MAX files were never stored (404).

## Regulars
~1,000 users with ≥ 8 Millys and ≥ 20 entries/week. First-half ROI does not predict second-half ROI (r = −.01). Top-decile regulars vs the rest: slightly more QB+2/QB+3, more distinct QBs (12 vs 11 per ~100 entries), lower max exposure (62% vs 66%).
